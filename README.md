# ПДД РФ 2026 — Умный тренажер с глубокими фильтрами

Веб-приложение для подготовки к теоретическому экзамену ГИБДД (категории A, B, M).
Все 800 официальных вопросов (40 билетов × 20) с комментариями и иллюстрациями выгружены с Drom.ru
и размечены ИИ по единой спецификации — [docs/TAGGING_SPEC.md](docs/TAGGING_SPEC.md).

Рабочая версия: **https://grzxk.ru/pdd/**

## Фильтры

Все фильтры сочетаются между собой (внутри группы — «любой из», между группами — «и»),
счетчики у каждого варианта пересчитываются на лету.

- **Режим подготовки**: Все / Новые / Ошибки (последний ответ неверный) / **Были ошибки**
  (ошибались хоть раз, даже если потом исправили) / Верные / Избранное.
- **Быстрые подборки**:
  - **Числа и нормы** — только вопросы, где нужно знать конкретное число
    (скорость, метры, мм протектора, проценты, сроки), а не любые вопросы с цифрами;
  - **Ловушки** — интуитивный ответ неверен или всё решает мелкая деталь;
  - **Мои частые ошибки** — ошибались 2 раза и больше;
  - **Давно не повторял** — отвечали больше 7 дней назад;
  - **Часто ошибаются все** — по общей статистике пользователей (≥ 40% ошибок).
- **Сложность**: легкие / средние / сложные.
- **Какое число нужно знать**: скорость, расстояния, размеры (мм), сроки, проценты, масса, возраст, количество.
- **Что спрашивают**: кто проедет первым, можно ли, как действовать, значение знака, траектория,
  ответ — число, термины, прочие факты.
- **Темы** (23 официальные темы экзамена) с режимом «Любая / Все».
- **Участники и обстановка**: трамвай, пешеходы, велосипедисты, спецтранспорт, регулировщик,
  светофор, ж/д переезд, круговое движение, дети, ночь/туман/гололед и др.
- **Тип вопроса** (с картинкой / без), **число вариантов**, **билеты** (сетка 1–40 с прогрессом),
  **блок вопросов** (1–5, 6–10, …), **поиск** по словам (и в пояснениях).
- **Порядок**: по порядку, вперемешку, сложные сначала, мои ошибки сначала.

После ответа показываются ИИ-подсказки: «Запомнить» (суть правила), «Норма» (число),
«Подвох» и ваша история попыток по вопросу.

## Аккаунт и хранение прогресса

Вход только по логину (без пароля). Каждая попытка ответа сохраняется на сервере (SQLite),
поэтому вся история ошибок не теряется — даже после исправления. Без входа прогресс хранится
в `localStorage`; при первом входе он переносится в аккаунт. Ответы, сделанные без сети,
копятся в очереди и отправляются позже.

## Клавиатура
`1`–`5` — ответ, `→` / `Пробел` — далее, `←` — назад, `F` — избранное, `R` — заново,
`/` — поиск, `Esc` — закрыть окно. Прямая ссылка на вопрос: `#125` (сквозной номер 1–800).

## Структура проекта
- `index.html`, `style.css`, `app.js` — приложение (Vanilla JS, без зависимостей).
- `pdd_data.js` — база 800 вопросов с ИИ-разметкой (`ai`) и разделами ПДД (`sections`).
- `server.py` — сервер: статика + API прогресса (`/api/login`, `/api/progress`, `/api/events`,
  `/api/global-stats`), только стандартная библиотека Python.
- `ai_tagger.py` — прогон вопросов через LLM, кэш в `pdd_ai_tags.json`.
- `build_data.py` — вливает `pdd_ai_tags.json` в `pdd_data.js`.
- `docs/TAGGING_SPEC.md` — спецификация разметки.
- `scraper.py`, `download_images.py`, `convert_images.py` — выгрузка исходных данных.
- `start_server.bat` — локальный запуск сервера на http://localhost:5050.

## Переразметка вопросов
```bash
LLM_API_KEY=... python3 ai_tagger.py --base http://localhost:20128/v1 --model agy/gemini-3.5-flash-lite
python3 build_data.py
```

## Деплой (grzxk.ru/pdd)
- Код: `/opt/pdd-trainer/app`, база пользователей: `/opt/pdd-trainer/data/pdd_users.db`.
- Сервис: `pdd-trainer.service` (`server.py` на `127.0.0.1:8796`).
- nginx (`grzxk.ru`): `/pdd/` — статика, `/pdd/api/` — прокси на сервис.
- Обновление: `cd /opt/pdd-trainer/app && git pull && sudo systemctl restart pdd-trainer`.
