# ПДД РФ 2026 — Умный тренажер с глубокими фильтрами

Автономное веб-приложение для подготовки к теоретическому экзамену ГИБДД (категории A, B, M).
Все 800 официальных вопросов с комментариями и иллюстрациями выгружены с Drom.ru и размечены интеллектуальными семантическими тегами.

## Ключевые возможности и фильтры

1. **Глубокая фильтрация**:
   - **«Числа и цифры»** (139 вопросов): все билеты, где фигурируют скорости (20/40/60/90/110 км/ч), дистанции и расстояния (в метрах), сроки лишения прав, промилле, проценты светопропускания стекол, остаточная глубина протектора в мм.
   - **«Пешеходы и переходы»** (50 вопросов): зебры, непредоставление преимущества, слепые пешеходы с белой тростью, посадка/высадка из трамвая.
   - **«Трамваи и регулировщик»** (72 вопроса): сигналы регулировщика, трамвайные пути, приоритет рельсового транспорта.
   - **«Перекрестки»** (233 вопроса): равнозначные, неравнозначные, круговое движение, регулируемые.
   - **«Остановка и стоянка»** (153 вопроса): четные/нечетные числа месяца, расстояние до переездов/остановок/пешеходных переходов.
   - **«Скоростной режим»** (81 вопрос): населенный пункт, жилые зоны, вне города, автомагистраль, буксировка.
   - **«Неисправности авто»** (49 вопросов): запрещение эксплуатации vs запрещение движения, люфты рулевого управления, внешние световые приборы.
   - **«Первая помощь»** (37 вопросов): жгуты при кровотечениях, сердечно-легочная реанимация, транспортировка пострадавших.
   - **«Штрафы и законы»** (32 вопроса): лишение прав, оформление европротокола, ОСАГО, обязанности водителя.
   - **«Вопросы-ловушки»** (181 вопрос): темы с традиционно высоким процентом ошибок на реальном экзамене.
   - **«Только с фото»** (548 вопросов) vs **«Только текст»** (252 вопроса).

2. **Дополнительные фильтры** (все сочетаются между собой, счетчики пересчитываются на лету):
   - **Режим подготовки**: Все / Новые (без ответа) / Ошибки / Верные / Избранное.
   - **Сочетание тем**: «Все» (вопрос относится ко всем выбранным темам) или «Любая» (хотя бы к одной).
   - **Тип вопроса**: с картинкой / без картинки; **количество вариантов ответа**: 2 / 3 / 4+.
   - **Несколько билетов сразу** (сетка 1—40 с цветовой индикацией прогресса по билету).
   - **Блок вопросов в билете**: 1–5, 6–10, 11–15, 16–20.
   - **Порядок**: по порядку или вперемешку.
   - **Поиск** по нескольким словам (е/ё не различаются), с подсветкой совпадений и опцией поиска в пояснениях.
   - Выбранные фильтры запоминаются между сессиями.

3. **Персональные режимы обучения**:
   - **Режим «Ошибки»**: вопросы с неверными ответами открываются для повторного решения — правильный ответ исправляет статистику.
   - **«Заново»**: любой отвеченный вопрос можно решить повторно.
   - **Избранное**: сохранение трудных вопросов в личный список для повторения.

4. **Клавиатурные шорткаты**:
   - `1`–`5` — выбор варианта ответа.
   - `→` / `Пробел` — следующий вопрос, `←` — предыдущий.
   - `F` — в избранное, `R` — ответить заново, `/` — поиск, `Esc` — закрыть окно.

5. **Интерфейс**:
   - Светлая и темная тема (по умолчанию — как в системе, выбор запоминается).
   - Адаптивная верстка: на телефонах и планшетах фильтры открываются выдвижной панелью, кнопки навигации закреплены снизу.
   - Увеличение иллюстраций по клику.
   - Прямые ссылки на вопрос: `index.html#125` — сквозной номер вопроса (1—800).

6. **Автономность**:
   - Полностью Vanilla JS/CSS (никаких внешних библиотек или npm).
   - Работает напрямую через открытие `index.html` (или через встроенные батники `start_browser.bat` / `start_server.bat`).
   - Прогресс и история ответов сохраняются в `localStorage` браузера (и в `user_progress.json`, если запущен `server.py`).

## Структура проекта
- `index.html` — главное приложение.
- `style.css` — адаптивные светлая и темная темы.
- `favicon.svg` — значок ГИБДД (иконка вкладки).
- `app.js` — движок фильтрации, тестирования и аналитики.
- `pdd_data.js` — полная база 800 вопросов с тегами.
- `pdd_raw.json` / `pdd_tagged.json` — сырые и размеченные JSON-дампы.
- `scraper.py` — скрипт скачивания актуальных билетов с Drom.ru.
- `tagger.py` — анализатор семантических признаков и генератор тегов.
- `start_browser.bat` — запуск в браузере в один клик.
- `start_server.bat` — локальный HTTP-сервер.
