# Спецификация ИИ-разметки вопросов

Все 800 вопросов прогоняются через LLM (`agy/gemini-3.5-flash-lite`, OpenAI-совместимый API)
скриптом `ai_tagger.py`. Модель получает текст вопроса, варианты, номер правильного ответа,
пояснение и признак «есть картинка» и возвращает строго JSON по схеме ниже.
Результат кэшируется в `pdd_ai_tags.json` (`{id: {...}}`), затем `build_data.py`
вливает его в `pdd_data.js`. Повторный запуск дообрабатывает только недостающие вопросы.

Принцип: каждое поле отвечает на **один** вопрос пользователя-фильтра и имеет закрытый
список значений, чтобы фильтры были непересекающимися и предсказуемыми.

## Поля

### `topics` — темы экзамена (1–3, первая — основная)
Соответствуют официальным темам билетов ГИБДД.

| id | Название |
|---|---|
| `general` | Общие положения, термины |
| `driver_duties` | Обязанности водителя, документы |
| `special_signals` | Спецсигналы, аварийка, знак аварийной остановки |
| `signals_adjuster` | Светофоры и регулировщик |
| `signs` | Дорожные знаки |
| `markings` | Дорожная разметка |
| `maneuvering` | Начало движения, повороты, развороты, задний ход |
| `lane_position` | Расположение на проезжей части, полосы |
| `speed` | Скорость движения |
| `overtaking` | Обгон, опережение, встречный разъезд |
| `stopping_parking` | Остановка и стоянка |
| `intersections` | Проезд перекрестков |
| `pedestrians` | Пешеходные переходы, остановки маршрутных ТС |
| `railway` | Железнодорожные переезды |
| `highway_residential` | Автомагистрали и жилые зоны |
| `route_vehicles` | Приоритет маршрутных ТС |
| `lights_horn` | Внешние световые приборы и звуковой сигнал |
| `towing` | Буксировка |
| `passengers_cargo` | Перевозка людей и грузов, учебная езда |
| `malfunctions` | Неисправности и условия эксплуатации |
| `safety` | Безопасность и техника управления |
| `first_aid` | Первая помощь |
| `liability` | Ответственность водителя, ОСАГО, ДТП |

### `format` — что именно спрашивают (ровно одно)

| id | Название | Признак |
|---|---|---|
| `who_first` | Очередность проезда | «Кто проедет первым», «в каком порядке», «вы должны уступить?» |
| `allowed` | Можно ли / разрешено ли | Да/нет о допустимости действия в ситуации |
| `action` | Как действовать | «Как следует поступить», «что обязан сделать» |
| `meaning` | Значение знака/разметки/сигнала | Что означает, на что распространяется, какой знак |
| `trajectory` | Траектория и полоса | По какой траектории / из какой полосы / где развернуться |
| `value` | Число / значение | «Сколько», «на каком расстоянии», «с какой скоростью», «какой срок» |
| `definition` | Термин | «Что называется…», «кто считается…» |
| `fact` | Прочие факты | Первая помощь, ответственность, техника — правильное утверждение |

### `memorize_number` — нужно ли **запомнить число**
`true`, только если правильный ответ невозможно дать, не зная конкретного числового
значения из ПДД/закона (скорость, метры, мм протектора, проценты, сроки, масса, возраст,
количество). Не считается: цифры только в нумерации вариантов/знаков, числа, видимые на
картинке и не требующие знания нормы, «2 полосы» на рисунке и т.п.
Это основа фильтра «Числа и нормы» — вместо старого «есть любая цифра».

`number_kind` (если `memorize_number`, иначе `null`):
`speed` · `distance` · `dimension` (мм, глубина, люфт, габарит) · `time` (сроки, часы, дни, годы) ·
`percent` · `mass` · `age` · `count` · `other`.

`number_value` — само число с единицей, коротко («1,6 мм», «50 м», «20 км/ч»), иначе `null`.

### `difficulty` — сложность 1–3
1 — очевидно/здравый смысл; 2 — нужно знать конкретное правило; 3 — легко ошибиться:
исключения, похожие варианты, несколько правил сразу, контринтуитивный ответ.

### `trap` — вопрос-ловушка
`true`, если интуитивный/«бытовой» ответ неверен или решает мелкая деталь (табличка,
тип ТС, время суток, слово «только»/«обязан»). `trap_reason` — короткое (≤ 80 симв.) пояснение.

### `involves` — участники и обстановка (0–5)
`tram` · `pedestrian` · `cyclist` · `motorcycle` · `route_vehicle` (автобус/троллейбус) ·
`emergency` (ТС со спецсигналами) · `adjuster` · `traffic_light` · `railway` · `roundabout` ·
`truck_trailer` · `children` · `bad_conditions` (ночь, туман, гололед, плохая видимость) ·
`tunnel_bridge` · `mountain_road`.

### `key_fact` — правило «запомнить» (≤ 140 символов)
Одна фраза — суть правила, по которому решается вопрос. Показывается после ответа
с пометкой «ИИ-подсказка».

## Детерминированные поля (без LLM, `build_data.py`)
- `sections` — номера разделов ПДД из ссылок в пояснении (`punkt_13_…` → `13`).
- `has_image`, число вариантов — как и раньше.

## Валидация
Ответ модели нормализуется: неизвестные значения отбрасываются, списки обрезаются по лимиту,
при невалидном JSON — до 3 повторов. Вопросы без валидного ответа остаются с пустой разметкой
и попадают в фильтры только по детерминированным признакам.
